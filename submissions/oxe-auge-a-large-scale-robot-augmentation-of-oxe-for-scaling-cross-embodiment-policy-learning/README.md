# OXE-AugE Reproduction Evidence

This repository provides deterministic, independently executable CPU-only reproduction evidence for the ICML 2026 paper:
**OXE-AugE: A Large-Scale Robot Augmentation of OXE for Scaling Cross-Embodiment Policy Learning** (`LcswwEzzX7`).

## Quickstart

```bash
python generate_evidence.py
pytest tests/
```
