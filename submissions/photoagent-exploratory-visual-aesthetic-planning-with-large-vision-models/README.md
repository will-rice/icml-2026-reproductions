# PhotoAgent: Exploratory Visual Aesthetic Planning with Large Vision Models

This Space presents the empirical audit and verification artifacts for the ICML 2026 paper **PhotoAgent: Exploratory Visual Aesthetic Planning with Large Vision Models** (Paper ID: `Ws8swqL5ob`, ArXiv: `2602.22809`).

## Overview & Targeted Claims
PhotoAgent formulates autonomous image editing as long-horizon decision-making using Large Vision Models (LVMs), tree search planning, aesthetic intent reasoning, and closed-loop visual feedback.

### Key Target Claims
1. **Long-Horizon Decision Making**: Formulates photo editing with tree search, memory, visual feedback, and closed-loop execution.
2. **UGC-Edit Dataset**: 7,000 authentic user-generated photos annotated with human aesthetic scores for reward modeling.
3. **1,017-Photo Benchmark**: Evaluation across portrait, landscape, urban, food, object, and low-light scenarios.
4. **User Preference & SOTA Performance**: 20-participant study showing consistent preference over baseline editing methods.
