# NorMuon Evidence Summary

This Space presents a deterministic evidence bundle for two selected NorMuon
mechanism claims:

- Algorithm 1 combines Muon orthogonalized updates with neuron-wise adaptive
  normalization from second-order momentum statistics.
- The adaptive normalization mechanism reduces uneven per-neuron update norm
  contributions in a CPU synthetic check.

The evidence does not reproduce the paper's large-scale LLM pretraining,
5.4B validation-loss, memory, or Modded-NanoGPT claims.
