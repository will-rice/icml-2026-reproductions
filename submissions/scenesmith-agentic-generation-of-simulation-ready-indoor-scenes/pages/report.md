# SceneSmith Evidence Report

This submission verifies the released SceneSmith source tree at commit
`67cc408fd38334b4a926efef45e284302ed5055b`.

The evidence harness statically checks the public code/configuration for the
hierarchical generation pipeline, planner/designer/critic agent roles,
asset-generation and retrieval integration, physical validation/export support,
and robot-evaluation modules.

Paper-scale generated-scene metrics and the 205-participant user study are
marked unavailable because the pinned source snapshot does not include
machine-readable records sufficient to recompute those claims independently.
