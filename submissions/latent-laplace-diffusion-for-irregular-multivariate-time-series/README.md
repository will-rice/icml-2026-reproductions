# Latent Laplace Diffusion for Irregular Multivariate Time Series Reproduction

This package provides reproduction evidence for ICML 2026 paper `t73XUJvyQr` (*Latent Laplace Diffusion for Irregular Multivariate Time Series*).

## Claims Verified

1. **Latent Horizon Generation**: Low-dimensional trajectory evaluation without ODE/SDE time-step integration.
2. **Stable Laplace Poles**: Parameterized mean evolution in the Laplace domain with stable complex-conjugate poles.
3. **Gap-Aware Conditioning**: Renewal-averaging gap mapping for irregular sampling intervals.
4. **Target Horizon Imputation**: Historical timestamp evaluation for missing-value imputation without model retraining.
