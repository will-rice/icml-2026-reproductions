# RoboMME Reproduction

This Space presents a CPU-only evidence bundle for the ICML 2026 Agent Repro
Challenge paper `8m30ogkPk2`.

The bundle verifies released artifact structure for the selected claims:
RoboMME task taxonomy, released training timestep metadata, and MME-VLA model
variant structure. It does not claim simulator success rates, real-world robot
experiments, resource efficiency, or GPU-scale model performance.
