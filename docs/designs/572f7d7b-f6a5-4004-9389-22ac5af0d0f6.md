## Scientific Architecture and Implementation Plan

### Overview
Top-W decoding improves text generation quality and diversity by leveraging token embedding geometry to prune candidate token sets. Unlike standard Top-$p$, Top-$k$, or Min-$p$ truncation which treat candidate tokens as an unmetricized set, Top-W formulates candidate selection as minimizing an optimal transport (Wasserstein distance) cost regularized by entropy and mass penalties.

### Mathematical & Algorithmic Formulation
1. **Distance Metric**: Token embedding distances $D_{ij} = \|e_i - e_j\|_2^2$ or cosine distance $1 - \cos(e_i, e_j)$.
2. **Wasserstein Truncation Objective**: Given next-token logit distribution $p(x)$ over vocabulary $V$, Top-W selects a candidate subset $S \subseteq V$ minimizing:
   $$\min_{S} \quad W(p_S, p) - \lambda_{\text{ent}} H(p_S) + \lambda_{\text{mass}} (1 - \text{mass}(S))^2$$
   where $p_S$ is the re-normalized distribution over subset $S$.
3. **Alternating Solver (Algorithm 1 / Section 4.2)**:
   - Initialize candidate pool $S_0$ using Top-$k$ / Top-$p$ pre-truncation.
   - Iteratively update subset $S_k \to S_{k+1}$ by updating dual variables and thresholding token costs.
   - Normalize final probability vector over $S^*$ and sample next token.

### Reproduction Test Suite & Verification Pipeline
1. **Algorithm 1 Unit Test**: Validate Top-W subset selection against exact Wasserstein distance formulation on synthetic logit/embedding inputs.
2. **Baseline Comparators**: Implement Min-$p$, Top-$p$, and Top-$H$ truncation schemes.
3. **GSM8K Metric Evaluation**: Evaluate token selection overlap, entropy preservation, and reasoning step accuracy on GSM8K benchmark logit traces across temperatures $T \in \{0.2, 0.7, 1.0\}$.
4. **Machine-Readable Artifacts**: Emit `results.json` adhering to the ICML 2026 challenge schema with claim statuses, tolerances, and runtime telemetry.
