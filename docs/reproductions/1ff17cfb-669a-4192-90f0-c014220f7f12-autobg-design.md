## Claims

The reproduction will audit five challenge claims:

1. ArBG replaces flow-based Boltzmann generators with an autoregressive model
   while retaining exact likelihoods and importance sampling.
2. ArBG avoids normalizing-flow invertibility/topology constraints and supports
   sequential inference-time interventions.
3. Released artifacts report improvements over flow-based Boltzmann generators,
   especially on 10-residue Chignolin.
4. Robin is released as a 132M-parameter transferable ArBG model.
5. Robin reports more than 60 percent zero-shot E-W2 energy-error reduction on
   8-residue systems relative to the previous state of the art.

## Evidence Plan

Use deterministic static and metadata checks against pinned public artifacts.
The generator will clone or query the pinned code tree, inspect implementation
symbols for autoregressive likelihood/scoring, importance sampling, intervention
paths, benchmark/evaluation scripts, and model-loading code, then query the
pinned Hugging Face model/dataset metadata for checkpoint size, license, and
file hashes.

The submission will not download the full 1.06 GB checkpoint or full trajectory
dataset during routine validation. It will record LFS pointer metadata and Hub
file metadata as artifact observations, and mark any benchmark headline metrics
as unavailable unless a pinned released result table is present in the code or
model card. No paper-reported number will be treated as a reproduced
measurement.

## Validation

The first test will fail until `generate_evidence.py` emits machine-readable
claim records with pinned revisions, source hashes, Robin metadata, dataset
metadata, and explicit unavailable notes. Validation will then run the evidence
generator, submission pytest, root pytest, skill quick validation, and
pre-commit in a clean controller worktree.
