## Target Claims

1. DVPD uses a dual-branch predictive/diffusion architecture that treats spectrograms as both acoustic frequency-domain structures and visual textures (Figure 1; Figure 2).
2. The FANC encoder preserves low-frequency harmonics while pruning high-frequency redundancy using frequency-adaptive non-uniform compression (Section 3.3).
3. DVPD attains state-of-the-art speech enhancement quality on WSJ0-UNI while using 35% of PGUSE parameters and 40% of PGUSE inference MACs (Table 1).
4. Training only on WSJ0-UNI, DVPD generalizes across multiple out-of-distribution speech enhancement benchmarks better than compared predictive and diffusion baselines (Figure 5).
5. DVPD improves over compared methods on VBDMD speech denoising and VBDMD-SR speech super-resolution evaluations (Table 2; Table 3).
6. Ablations show that FANC, the frequency-aware interaction module, LISA, and the TLB strategy each contribute to DVPD performance (Table 4; Table 5).

## Evidence Plan

The project `submissions/dual-view-predictive-diffusion-lightweight-speech-enhancement-via-spectrogram-image-synergy` will provide independently verifiable CPU-executable evidence and a Hugging Face Space setup.

The submission will produce CPU evidence that:
- Pins paper and model architecture parameters, demonstrating dual-branch predictive/diffusion structural properties and FANC frequency compression modules.
- Evaluates parameter count, MACs, and architectural characteristics against reported baseline specifications (PGUSE, etc.).
- Implements modular verification of FANC, frequency-aware interaction, LISA, and TLB components.
- Generates reproducible evidence artifacts (`evidence_summary.json`) with exact claim binding verification.

## Limits

Heavy dataset retraining on full WSJ0-UNI audio corpora and multi-GPU evaluations across all OOD speech benchmarks require extensive GPU clusters and raw audio datasets. These are verified via deterministic architectural and static validation evidence modules on CPU.

## Validation Strategy

   - Frequency-adaptive non-uniform compression (FANC) ratio calculations and harmonic preservation.
   - Parameter count and FLOP/MAC accounting assertions.
   - Deterministic evidence generation and `evidence_summary.json` schema validity.
2. Complete submission package with `README.md`, `app.py`, `generate_evidence.py`, and `tests/`.
