## Evidence Output Contract

Implementation will live under `submissions/less-is-enough-synthesizing-diverse-data-in-feature-space-of-llms/` with:

- `pyproject.toml` and pytest suite for deterministic CPU execution.
- `fac_evidence/` for artifact manifests, TeX parsing, toy FAC computation, and report generation.
- `evidence/manifest.json`, `evidence/claims.json`, and `pages/report.md`.
- No credentials, no downloaded model weights, no paper-reported values labeled as reproduced measurements.

Expected runtime is under 30 minutes on CPU with zero paid API cost. Full SAE training, LLaMA/Mistral/Qwen synthesis, downstream fine-tuning, AlpacaEval/GPT-4 evaluation, RewardBench evaluation, and CAA steering evaluation are out of scope for this CPU-only attempt.

## Risks And Blockers

- The structured Hugging Face dataset API is inaccessible (`401`), so raw synthetic datasets may be unavailable.
- The checkpoint repos are public but model-weight execution requires large downloads and GPU; this design avoids using them as executable dependencies.
- Claims 3, 4, and 5 include large-scale performance results. They must be downgraded unless raw outputs or CPU-feasible released evaluation artifacts are found.
