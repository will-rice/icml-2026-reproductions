# DHSA Recovery Design

Attempt `020e5035-01ad-40a7-9ab0-9147289ab70c` is a recovery of a prior
validated lane whose source commit is not present in the controller checkout.

The replacement evidence is intentionally narrow:

- pin public upstream artifacts from `sxiong/DHSA` and
  `sxiong/DHSA_Long-Data-Collections`;
- recompute dataset length-bucket totals from the pinned JSON summary;
- run a deterministic sparse-routing simulation comparing content-adaptive
  hierarchical selection against a static block-sparse selection at equal token
  budget;
- render all computed numbers into `pages/*.md`;
- mark full LongBench and 4-bit latency claims as `inconclusive` unless those
  experiments are actually executed.

This design avoids paper-reported benchmark values as reproduced measurements.
